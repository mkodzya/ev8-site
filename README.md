# EV8 — сайт

Новый сайт ev8.ge: подписка на электромопед для курьеров в Тбилиси. Заменяет сайт на WordPress.
Собран на Astro, отдаётся статичными файлами.

Предпросмотр: <https://test.ops.ev8.ge/garage/site/> (грузинский) и `/en/` (английский). Русской версии
нет; `src/i18n/ru.ts` — исходный текст, с которого пишутся две другие.

## Что уже есть

- Главная: карусель главных выгод, гараж, очередь на новые мопеды, блок «Права, регистрация и налог»,
  шаги, вопросы.
- Гараж (`/models/`): XL1200, Eagle, S70 Pro — тёмная страница, стрелки, карточки, свайп, по кругу.
- Заявка (`/subscription/`): мопед, снаряжение в рассрочку, услуги и страховка, калькулятор заработка
  со сравнением с бензиновым мопедом. Числа калькулятора и цены снаряжения — черновики
  (`src/data/subscription.ts`, с источниками); то, у чего нет цены, показано как «уточняется».
- Заявка в очередь уходит письмом на почту компании: конструктор спрашивает имя и телефон и
  отправляет заявку на сервер EV8 Ops. Если сервер не ответил или почта ещё не настроена —
  открывается WhatsApp с тем же сообщением.
- Кнопки «Написать в WhatsApp» на страницах: три вопроса, затем сообщение с ответами. Плавающей
  кнопки «Написать» нет (убрана 07.10.2026). Заявка в Kommo появится, когда будет ключ (реестр
  книги, п. 5).
- «Станции» (`/stations/`), «Права AM» (`/am-licence/`), «Как это работает» (`/how-it-works/`),
  «Вопросы и ответы» (`/faq/`), «Контакты» (`/contacts/`).

## Чего ещё нет

«Налог 1 %» (ждёт ставок от бухгалтерии) и «Заявка принята» (появится с формой заявки в Kommo);
переадресации со старых адресов; боевой адрес. Грузинский текст (`src/i18n/ka.ts`) — черновик, его
ещё не читал носитель языка.

## Для Kardu: как начать

1. Принять приглашение: <https://github.com/mkodzya/ev8-site/invitations>.
2. Склонировать и включить защиту от случайной отправки в `main`:

```bash
git clone git@github.com:mkodzya/ev8-site.git && cd ev8-site && git config core.hooksPath .githooks
```

3. Работать в ветке `feature/<тема>` от `develop`, готовое сливать в `develop`. В `main` и теги —
   не отправлять: релизы выпускает Mika.
4. Посмотреть сайт у себя: с Docker — `scripts/build.sh preview`; с Node 22 — `npm install`, затем
   `npm run dev`.
5. На тестовый адрес правки выкладываются сами: через минуту-две после слияния в `develop`
   (ход видно на GitHub, вкладка Actions, «Deploy»). На боевой адрес сайт попадает, только когда
   Mika сливает `develop` в `main`.
6. Менять нужно только этот репозиторий. EV8 Ops (`mkodzya/ev8-ops`) и его стенды меняет сессия
   Mika: если сайту что-то требуется от сервера, как счётчик или цена бензина, — написать Mika.

Тексты лежат в `src/i18n/` (`ka.ts`, `en.ts`; `ru.ts` — исходный смысл, на сайте его нет), цены и
модели — в `src/data/`. Проверка, что в трёх языках одни и те же ключи: `npm run check`.

## Сборка

Node на Mac нет — всё в Docker:

```bash
scripts/build.sh preview
```

Выкладывать руками не нужно: сборку и выкладку делает GitHub (`.github/workflows/deploy.yml`).

Правила — в `CLAUDE.md`. Решения и открытые вопросы — в книге проекта `mkodzya/ev8-handbook`.
