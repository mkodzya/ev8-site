# EV8 — сайт

Новый сайт ev8.ge: подписка на электромопед для курьеров в Тбилиси. Заменяет сайт на WordPress.
Собран на Astro, отдаётся статичными файлами.

Предпросмотр: <https://test.ops.ev8.ge/garage/site/> (грузинский), `/en/`, `/ru/` — русский только в
предпросмотре, для согласования смысла.

## Что уже есть

- Главная: заголовок, квиз из трёх вопросов с предложением под профиль, гараж, четыре шага, состав
  подписки, вопросы, заявка.
- Гараж (`/models/`): XL1200, Eagle, S70 Pro — стрелки, карточки, свайп, по кругу.
- Заявка — сообщение в WhatsApp, которое курьер отправляет сам: имя, мопед и ответы квиза подставлены.
  Заявка в Kommo появится, когда будет ключ (реестр книги, п. 5).

## Чего ещё нет

Страницы «Подписка» (конструктор и калькулятор), «Как это работает», «Вопросы и ответы», «Налог 1 %»,
«Контакты», «Заявка принята»; переадресации со старых адресов; боевой адрес.

## Сборка

Node на Mac нет — всё в Docker:

```bash
scripts/build.sh preview
```

```bash
scripts/deploy-preview.sh
```
